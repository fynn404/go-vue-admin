# 更新日志

本文档记录 Go-Vue-Admin 项目的版本更新历史。

## [1.0.0] - 2024-03-21

### 新增
- 用户管理系统
  - 多角色支持（学生、教师、管理员）
  - 用户认证与授权
  - 个人信息管理

- 课程管理系统
  - 课程创建与编辑
  - 课程状态管理
  - 课程容量控制
  - 课程列表查看与搜索

- 选课系统
  - 学生选课功能
  - 课程容量限制
  - 选课状态追踪
  - 已选课程管理

- 成绩管理系统
  - 教师成绩录入
  - 成绩统计分析
  - 成绩分布可视化
  - 成绩历史记录

### 技术栈
- 后端
  - Go 1.16+
  - Gin Web Framework
  - GORM
  - JWT Authentication
  - MySQL 5.7+

- 前端
  - Vue 3
  - Vue Router
  - Pinia
  - Element Plus
  - ECharts
  - Axios

### 部署支持
- Docker 容器化部署
- Nginx 反向代理
- MySQL 数据库配置
- 环境变量配置

## 版本号说明

版本号格式：主版本号.次版本号.修订号

- 主版本号：重大功能变更，可能包含不兼容的 API 修改
- 次版本号：新功能添加，但保持向后兼容性
- 修订号：问题修复和小的改进

## 贡献指南

1. 版本更新流程
   - 创建功能分支
   - 开发新功能
   - 提交代码审查
   - 合并到开发分支
   - 发布新版本

2. 提交信息规范
   - feat: 新功能
   - fix: 修复问题
   - docs: 文档更新
   - style: 代码格式
   - refactor: 代码重构
   - test: 测试相关
   - chore: 构建过程或辅助工具的变动

- 最新版本：完整支持

- 更早版本：不再维护

### 更新周期
- 主版本：6-12个月
